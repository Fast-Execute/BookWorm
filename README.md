# BookWorm

A multi-technology digital library project by Fast-Execute.

## Project status

Foundation setup in progress.

See `PROJECT_PROGRESS.md` for the live development tracker.

## Product direction

- Digital book library
- PDF book management
- Reading progress
- User accounts and cloud storage
- Rewarded-ad book earning system
- Advertiser partnership workflow
- Secure administration

### Hidden admin entrance

The prototype design includes the seven-tap `b.` logo gesture as the admin entry point. This is a navigation mechanism, not a security boundary; production administration must use authenticated authorization.
