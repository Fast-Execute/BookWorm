# BookWorm Roadmap

## Phase 1 — Foundation

Repository, structure, documentation, and development tracking.

## Phase 2 — Library + PDF management

Build the library model, administrator book creation, PDF selection, upload, metadata, and library display.

## Phase 3 — Cloud + accounts

Add authentication, secure storage, database records, and permissions.

## Phase 4 — Reader

Add a reliable PDF reading experience and navigation.

## Phase 5 — Progress

Persist page position, reading progress, and reading goals.

## Phase 6 — Rewards

Connect verified rewarded advertisements to the book-reward workflow.

## Phase 7 — Advertisers

Prepare the advertiser-partnership workflow, campaign records, reward terms, and outreach documentation.

## Phase 8 — Security

Harden administrator authentication, authorization, storage rules, abuse controls, and audit logging.

## Phase 9 — Launch

Testing, release builds, deployment, monitoring, documentation, and production launch.
